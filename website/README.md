# PLAYCE Website

Static landing page for the Android + Wear OS project.

## Structure

- `index.html`: main landing page
- `privacy.html`: public privacy policy page
- `styles.css`: shared site styling
- `script.js`: mobile menu and reveal interactions
- `assets/`: local branding assets
- `vercel.json`: static deployment config

## Vercel

Set the Vercel project root directory to `website/`.

No build command is required.
