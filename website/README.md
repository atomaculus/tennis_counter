# PLAYCE Website

Static landing page for the Android + Wear OS project.

## Structure

- `index.html`: main landing page
- `download.html`: single smart download link that redirects iOS to App Store and Android to Google Play
- `privacy.html`: public privacy policy page
- `styles.css`: shared site styling
- `script.js`: mobile menu and reveal interactions
- `assets/`: local branding assets
- `vercel.json`: static deployment config
- `terms.html`: public Terms of Service page
- `favicon.svg`: site favicon
- `robots.txt`: crawler rules
- `sitemap.xml`: sitemap template, requires final production domain replacement

## Vercel

Set the Vercel project root directory to `website/`.

No build command is required.
