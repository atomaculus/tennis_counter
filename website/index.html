Does PLAYCE work for padel?¿PLAYCE funciona para pádel?+

Yes. The scoring engine handles padel with the same point / game / set / tiebreak rules as tennis, plus configurable formats like Fast4.

Do I need both a phone and a watch?¿Necesito teléfono y reloj a la vez?+
